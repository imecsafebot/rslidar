# RSLidar

A collection of C++ projects for working with RSLidar point-cloud data, including direct sensor access, people detection and tracking, and result visualization.

## Overview

This repository contains three separate C++ projects:

```text
                    RSLidar Sensor
                          │
                          ▼
                  ┌───────────────┐
                  │  rslidar_api  │
                  │               │
                  │ Sensor access │
                  │ Point clouds  │
                  └───────┬───────┘
                          │
                          ▼
                  ┌───────────────┐
                  │    People     │
                  │   Detection   │
                  │               │
                  │ Detection     │
                  │ Tracking      │
                  └───────┬───────┘
                          │
                          ▼
                    CSV Results
                          │
                          ▼
                  ┌───────────────┐
                  │    People     │
                  │    Viewer     │
                  │               │
                  │ Visualization │
                  └───────────────┘
```

The projects are maintained separately and each has its own `CMakeLists.txt`.

# Projects

## 1. RSLidar API

Directory:

```text
rslidar_api/
```

This project provides direct C++ access to the RSLidar sensor using the RSLidar/RoboSense SDK.

It receives LiDAR point-cloud data directly from the sensor without requiring ROS 2.

The API project is responsible for:

* Connecting to the RSLidar
* Receiving LiDAR packets
* Processing point-cloud frames
* Accessing point coordinates
* Accessing point intensity
* Providing point-cloud data to applications

### Build

```bash
cd rslidar_api
mkdir build
cd build
cmake ..
make -j$(nproc)
```

### Run

Run the generated executable according to the configuration in the project.

The RSLidar sensor must be connected and configured correctly before running the application.

# 2. People Detection and Tracking

Directory:

```text
people_detection/
```

This project processes LiDAR point-cloud data to detect and track people.

The processing pipeline includes:

```text
Point Cloud
     │
     ▼
Point Cloud Processing
     │
     ▼
Filtering
     │
     ▼
Clustering
     │
     ▼
People Detection
     │
     ▼
Tracking
     │
     ▼
Detection / Tracking Results
```

The output contains information associated with detected and tracked people, including their spatial position and tracking information.

### Build

```bash
cd people_detection
mkdir build
cd build
cmake ..
make -j$(nproc)
```

### Data

The original LiDAR recordings and test data are not included in this repository.

Captured data and test datasets are intentionally excluded from Git using `.gitignore`.

# 3. People Viewer

Directory:

```text
people_viewer/
```

The viewer provides visualization of the people detection and tracking results.

It can be used to inspect the results generated by the people detection project.

### Build

```bash
cd people_viewer
mkdir build
cd build
cmake ..
make -j$(nproc)
```

### Example

For a CSV result file:

```bash
./people_viewer <path-to-results.csv>
```

The exact command depends on the generated executable and the input format used by the detection project.

# Sensor

The projects were developed and tested using an RSLidar E1R LiDAR sensor.

The RSLidar communicates with the computer over Ethernet using UDP.

The point-cloud data contains information such as:

* X coordinate
* Y coordinate
* Z coordinate
* Intensity

The RSLidar API project uses the RSLidar/RoboSense SDK to receive the sensor data.

# ROS 2

The direct API project in this repository is intended to work without ROS 2.

# Data

Large sensor recordings and test datasets are not stored in this Git repository.

The following types of files are intentionally excluded:

```text

captures/
test_data/
*.pcd
*.pcap
*.mcap
*.bag
*.db3
```

This keeps the repository focused on source code and configuration rather than large sensor recordings.
